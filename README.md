# Sunrise System 🌅

نظام متكامل لإدارة حسابات البازارات، تم تطويره بلغة Python ليكون سريعاً وسهل الاستخدام.

## 🌟 مميزات البرنامج (Features)
* إدارة عمليات البيع بالعملات المختلفه.
* ادارة المصاريف وحسابات التجار.
* إدارة حسابات المالك والأرباح.
* تقارير مبيعات شاملة ومفصلة.
* واجهة مستخدم بسيطة وسريعة.

## 🛠️ التقنيات المستخدمة (Technologies)
* اللغة: Python
* واجهة المستخدم: Tkinter (أو اسم المكتبة التي استخدمتها)
* قاعدة البيانات: SQLite
